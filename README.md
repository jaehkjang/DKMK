# DKMK — 와인 셀러 앱

나와 아내가 같이 쓰는 와인 셀러 관리 모바일 웹앱. 온그린과 같은 구조로, 별도 서버 없이 **Google Apps Script + Google Sheets**만으로 동작합니다.

## 구조

- `Code.gs` — Apps Script 백엔드. 시트 CRUD, 사진 라벨 인식(Gemini API), 마심 표시, 요리 추천, 통계 API.
- `Index.html` — Apps Script `HtmlService`가 그대로 서빙하는 모바일 프런트엔드(HTML/CSS/JS 단일 파일). 별도 빌드/배포 없이 웹 앱 URL이 곧 모바일 앱 URL입니다.

DB는 기존에 쓰던 "와인리스트" 구글 스프레드시트를 그대로 사용합니다.

## 기능

1. 셀러 와인 목록(보유/마심 필터, 검색)
2. 라벨 사진 촬영 → AI가 와인명/종류/품종/생산지/빈티지 자동 인식 후 폼에 채움
3. 와인 상세 정보(잔, 서빙방법, 배경, 페어링) + 마실 때 별점/한줄평/함께한 음식 기록
4. 마신 와인은 "마심 보관함"으로 이동, 되돌리기 가능
5. 음식 입력 → 보유 와인 중 어울리는 것 추천
6. 월별/종류별/가격대별 소비 통계
7. 공유 PIN 로그인 (나 + 아내 공용)

## 배포 방법

1. "와인리스트" 스프레드시트 열기 → **확장 프로그램 → Apps Script**
2. `Code.gs`, `Index.html`(HTML 파일 이름은 정확히 `Index`) 내용을 그대로 붙여넣기
3. 프로젝트 설정 → **스크립트 속성**에 추가
   - `WINE_PIN` — 공유 로그인용 PIN
   - `GEMINI_API_KEY` — https://aistudio.google.com/apikey 무료 발급
4. 에디터에서 `setupColumns` 함수 1회 실행 (시트에 신규 컬럼 자동 추가, 기존 데이터 보존)
5. **배포 → 새 배포 → 웹 앱**
   - 실행 계정: 나
   - 액세스: **링크가 있는 모든 사용자** (PIN이 로그인 역할을 하므로 구글 로그인 없이 아내 폰에서도 접속 가능)
6. 배포된 웹 앱 URL을 모바일 브라우저에서 열고 홈 화면에 추가

## 버전 관리

기능 변경 시 이 리포지토리에 커밋 → Apps Script 에디터에 반영 → 새 배포. 별도 빌드 도구/패키지 매니저 없음.
