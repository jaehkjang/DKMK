와인 정보 채우기

품종·생산지·서빙온도·에어링시간·잔 추천(완벽한 잔 + 내 잔)·추천 음식(베스트 페어링 + 한국에서 구하기 쉬운 음식)·와인 배경·가격대(추정)가 비어 있는 와인을 한 번에 AI로 채워요. 이미 채워진 와인은 건드리지 않아요.

🍷 이용법

  1. 와인 추가 — 하단 "추가" 탭의 라벨 찍기 버튼을 눌러 사진을 찍으면 이름·품종·생산지가 자동으로 인식돼요.
  2. 와인 정보 확인 — 셀러 목록에서 와인을 누르면 서빙 온도, 어울리는 잔, 어울리는 음식이 자동으로 채워져 나와요.
  3. 페어링 추천 — 페어링 추천 탭에서 먹고 싶은 음식을 고르면 어울리는 와인을 찾아줘요. 음식 없이 오늘 그냥 마시기 좋은 와인만 추천받을 수도 있어요.
  4. 마시기 기록 — 와인을 마셨으면 "마시기" 버튼으로 별점·한줄평·재구매 의향을 남겨요.
  5. 기록 보기 — 기록 탭에서 지금까지 마신 와인 통계와, 같은 와인을 여러 번 마셨을 때의 평점 변화를 볼 수 있어요.
  6. 설정 — 비밀번호 변경, 내가 가진 잔 등록, 기존 와인 정보 한번에 채우기, 홈 화면에 추가/공유를 할 수 있어요.
