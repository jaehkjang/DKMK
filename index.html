와인 정보 채우기

품종·생산지·서빙온도·에어링시간·잔 추천(완벽한 잔 + 내 잔)·추천 음식(베스트 페어링 + 한국에서 구하기 쉬운 음식)·와인 배경·가격대(추정)가 비어 있는 와인을 한 번에 AI로 채워요. 이미 채워진 와인은 건드리지 않아요.

🍷 와인 딸까 말까가 하는 일

우리 집 와인 셀러를 관리하는 앱이에요. 아래 기능들을 둘러보세요.

📸 와인 추가

  • 라벨 찍기 — 사진 한 장이면 와인 이름·품종·생산지·종류를 AI가 알아서 읽어줘요. 카메라 대신 사진 라이브러리에서 골라도 돼요.
  • 셀러 찍기 — 여러 병을 한 번에 찍으면 각각 인식해서 원하는 것만 골라 담을 수 있어요.

🍇 와인 상세 정보 (자동 완성)

  • 서빙 온도 · 에어링(디캔팅) 시간
  • 잔 추천 두 가지 — 완벽한 잔(이상적인 잔) / 내 잔 추천(내가 등록해둔 잔 중 가장 잘 맞는 것), 별점으로 적합도 표시
  • 추천 음식 두 가지 — 클래식 페어링(구하기 쉬운지 무관, 이상적인 조합) / 제안 페어링(한국에서 구하기 쉬운 음식), 별점으로 적합도 표시
  • 와인 배경(스타일·유명한 이유 등), 국내 가격대(추정)
  • 빈티지는 AI가 절대 추측하지 않아요 — 라벨 사진에 실제로 보일 때만 채워요
  • 설정 → "보유 와인 정보 한번에 채우기"로 기존 와인들도 한 번에 채울 수 있어요

🍽️ 페어링 추천

  • 음식을 골라 "어울리는 와인 찾기" — 내 셀러에서 잘 맞는 와인을 별점·이유와 함께 추천하고, 셀러에 없어도 이 음식에 보통 잘 어울리는 스타일(지역·품종)도 알려줘요
  • "안주없이 마실 와인 추천받기" — 오늘 그냥 마시기 좋은 와인 추천
  • 정말 잘 어울리는 게 없으면 억지로 추천하지 않아요

🥂 마시기 기록

  • 별점, 한줄평, 함께한 음식, 재구매 의향(쟁여두고 싶다 / 가격 좋으면 산다 / 한 번이면 족하다)을 남길 수 있어요
  • 같은 와인을 두 번 이상 마시면 기록 탭에서 마실 때마다의 평점 변화를 볼 수 있어요

📊 기록(통계)

  • 지금까지 마신 와인 수, 종류별·품종별·월별·가격대별 통계를 그래프로 보여줘요

⚙️ 설정

  • 비밀번호 변경, 내가 가진 잔 등록/관리
  • 홈 화면에 추가 / 공유 — 앱처럼 바로 쓸 수 있게 설치하는 방법 안내
